# Phase 5 primary-gate rulings — 2026-08-20 (BINDING)

Coordinator-authored, closing P5 T1 (#37). Order of authority for every
Phase 5 task: **these rulings > the plan > the task's gate matrix > the
ticket**. Owner decision policy in force: best-recommended options are

## Cross-cutting rulings (RC)

**RC1 — Filament pin.** ONE pin for the whole phase:
`google/filament` **v1.75.0** (tag; commit
0e58877c09afb1aacd09ff640f74d2adcd2a7e80, Apache-2.0). Stage 2's
main-HEAD survey (721ec800...) remains valid research context; all
ports cite v1.75.0 file paths. Rationale: a release tag is a stable,
citable pin; cross-checks against main are advisory notes, not sources.

**RC2 — T2 scope WIDENED (resource-model gap, confirmed independently
by Stage 1 and Stage 3 research).** rx_graph/rx_rhi_vk today have:
single-mip attachments/transients, no cube/array texture concept, no
storage-image pass API, barriers hardcoding VK_REMAINING_MIP_LEVELS.
T9 (IBL bake), T22 (scene-color mips), and T31 (bloom) all need the
same primitives. Ruling: T2 lands the generic resource-model extension
ONCE — per-mip/per-layer subresource pass I/O, storage-image
read/write API (mirroring the existing StorageBuffer API shape per the
T2 matrix), cube/array views — with device-free + GPU tests. T9/T22/T31
consume; they do not extend.

**RC3 — Importer plumbing scope + charter erratum.** The charter's
"every listed material extension is already parsed and preserved" is
FALSE for transmission, volume, ior, clearcoat, anisotropy, specular
(WARN-log-only today; only emissive_strength is consume-ready). Ruling:
explicit importer-plumbing scope (parse → MaterialAsset fields →
value-asserted import tests) is folded into T21 (clearcoat/anisotropy/
specular), T23 (transmission/ior), T24 (volume). A registry erratum
correcting the charter note ships with this gate's commit. No task may
assume preserved fields without a value-asserted test proving them.

**RC4 — Transmission draw partition.** ViewLists gains a THIRD
partition (TRANSMISSION) with its own sort-key shape, never
instancing-collapsed, scheduled per the charter frame pipeline (after
opaque + scene-color mip capture, before ordinary BLEND). Overloading
BLEND is rejected. Lands in T23 with the partition's device-free
determinism tests; T25's blendOrder work builds on it.

**RC5 — Depth prepass + sampleable depth.** T15 (clustered shading
integration) OWNS the depth prepass called for by the charter frame
pipeline, delivering a sampleable scene-depth resource through the
graph. T19 (contact shadows) and T26 (SSR) hard-depend on it; neither
may ship a private depth copy. T1's spec section must define the
prepass's place in the pass chain (this ruling makes it mandatory, so
"whether" is closed; the spec defines "how").

**RC6 — Temporal seams corrected (plan erratum).** The plan/ticket
claim of pre-paid "prev-frame transforms in the transform pools" is
FALSE (test-only design note; no production API). Camera jitter and
render-graph history resources ARE real. Ruling: T33 (TAA) builds
production previous-transform storage + a velocity buffer as NEW work;
its matrix criteria stand with that sizing. The Stage 4 checkpoint may
not treat velocity as inherited.

**RC7 — Verification conventions for this phase.** (a) Real-driver
(NVIDIA) runs are mandatory per round and driver-labeled; lavapipe
remains the pixel-reference driver. (b) Live-timing/quality claims
(PCSS penumbra, TAA stability, froxel cost) publish real-driver
numbers only; lavapipe gates cheap smoke/monotonicity checks. (c)
Anything requiring an HDR display or human judgment gets honest
MANUAL_VERIFICATION rows. (d) On-desktop interactive verification is
serialized/announced/NICEd per the standing owner rule (see phase
ledger). (e) The byte-source invariant's "grep-enforced" wording
becomes TRUE: T6 adds the actual grep as a tools/ script + CI step
(closing the process gap found by the T6 matrix) — the fourth
repetition of an inaccurate phrase is rejected.

**RC8 — Benchmark/exit mechanism.** T36 BUILDS the CI perf-regression
gate mechanism (Phase 4 never delivered it — flagged honestly by Stage
4 research) plus the published-numbers discipline: desktop numbers
mandatory; Steam Deck rows honest-manual until Deck hardware enters
the loop. The Workshop asset is usable for LOCAL benchmarks only (not
scriptably fetchable — packaging skip-if-absent caveat applies); CI
perf gates run on scriptably-fetchable content (helmet grid, Sponza,
Bistro once converted).
